3. stale caches a later step would silently reuse
----------------------------------------------------------------------------
  04_families.sh decides whether to rebuild with 'if [ ! -f all.dmnd ]'.
  A database built from the old nine-species set would be reused against
  the current seventeen, and the printed species count comes from the
  variable rather than the database, so nothing would say so. Same shape
  as the KEGG query returning zero and the single-tip rooting returning
  all zeros. Removing the cache forces a rebuild; 04_ also needs a check
  that compares the cache against the species list.


4. outgroup GFF3 files
----------------------------------------------------------------------------
  The current pipeline reads only the taro GFF3. These were fetched to
  map rice and sorghum PSY genes to chromosomes for the subgroup
  question, which is recorded as not determinable. Re-downloadable with
  'datasets download genome accession <ACC> --include gff3', though a
  later NCBI release may differ, which is why the checksums are rescued.
